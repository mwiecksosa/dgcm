generate_add_effect_realizations.R

generate_corr_shock_realizations.R
- Code to generate the time series for the correlated shock simulations for the conditional independence test.

generate_indep_test_corr_shock_realizations.R
- Code to generate the time series for the correlated shock simulations for the (unconditional) independence test.

run_add_effect_sims.R
- Code to run the additive effect simulations for the conditional independence test.

run_corr_shock_sims.R
- Code to run the correlated shock simulations for the conditional independence test.

run_indep_test_corr_shock_sims.R
- Code to run the correlated shock simulations for the (unconditional) independence test.

sieve.R
- Code for the sieve estimation of the time-varying regression functions.

stock.rmd
