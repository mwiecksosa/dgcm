## Repository Contents

- **`dGCM_test.R`**  
  Implements the dynamic generalized covariance measure (dGCM) test.

- **`generate_add_effect_realizations.R`**  
  Generates time series realizations for the additive effect simulations of the conditional independence test.

- **`generate_corr_shock_realizations.R`**  
  Generates time series realizations for the correlated shock simulations of the conditional independence test.

- **`generate_indep_test_corr_shock_realizations.R`**  
  Generates time series realizations for the correlated shock simulations of the unconditional independence test.

- **`run_add_effect_sims.R`**  
  Runs the additive effect simulations for the conditional independence test.

- **`run_corr_shock_sims.R`**  
  Runs the correlated shock simulations for the conditional independence test.

- **`run_indep_test_corr_shock_sims.R`**  
  Runs the correlated shock simulations for the unconditional independence test.

- **`sieve.R`**  
  Implements sieve estimation of the time-varying regression functions.

- **`stock.Rmd`**  
  Contains the code for the real data application.
